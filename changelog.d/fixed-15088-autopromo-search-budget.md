- **Contributor-lane auto-promotion no longer trips GitHub's search secondary rate limit** ([#15088](https://github.com/hivecommons/hive/issues/15088)). The hive-wide merged-history search ([#14517](https://github.com/hivecommons/hive/issues/14517)) ran again for every open PR by an author on every sweep, and also ran for `[bot]` authors such as `github-actions[bot]`. On a 19-repository hive that took 3–4 Search API calls per PR, and the resulting secondary-limit refusals sent the hive into its rate-limit caution window five times in one evening, pausing merges and dashboard refreshes each time. Bots are now exempt from auto-promotion (they are trusted only through the trusted bot authors setting, never by counting merges), and each (repository, author) answer is cached for ten minutes; a failed search is not cached.
