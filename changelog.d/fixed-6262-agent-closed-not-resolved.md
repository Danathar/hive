- **The Advisory Digest no longer reports agent-closed findings as resolved.** Advisory agents (notably `guide`) re-check their own findings and `bd close` the ones they judge fixed; that judgement was rendered as a struck-through "resolved" entry even when nothing had changed, so still-open documentation gaps appeared under **Recently Resolved** ([#6262](https://github.com/hivecommons/hive/issues/6262)). **Recently Resolved** now lists only closes the hive has evidence for — a merged PR, closed GitHub references, or a healed access check. Other closes appear under a separate **Recently Closed by Agents — Fix Not Verified** section, without strikethrough, and the zero-findings digest no longer says "all previously reported findings are resolved" when only agent closes are behind it.
