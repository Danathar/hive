- **backend-smoke's pinned lane now tests the repository's own contributor image, not upstream's** (#6086). The lane exists to run the checkout's suite against the CLI binaries the contributor image actually ships, but it hard-coded `ghcr.io/hivecommons/hive-contributor:latest`, so a fork's lane silently exercised upstream's image and stayed green no matter what the fork shipped — while `docker.yml` already derives its push targets from `github.repository_owner`, meaning a fork published one image and tested another. The pull step now derives the image from the repository owner, falls back to the upstream image with a workflow warning when the owner-scoped one is not pullable (a fork that has not published yet still gets a meaningful run), and logs which image the lane pinned either way.
