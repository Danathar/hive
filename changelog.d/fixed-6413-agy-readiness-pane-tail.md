- Interactive `agy` (Antigravity) contributors now become ready instead of returning every task they are assigned ([#6413](https://github.com/hivecommons/hive/issues/6413)). `tmux capture-pane` pads its output to the full pane height, and agy renders inline at the top of the pane, so the relay's 15-line readiness window contained nothing but blank padding — a live, idle agy prompt classified as `starting` forever, every task prompt was queued rather than typed, and the task was handed back ten minutes later with `CLI never became ready`. `paneTail()` now counts non-blank lines, matching the Go helper of the same name in `src/pkg/agent/manager.go`, which fixes the same blind spot in agy's login/onboarding detection and in the transient-API-error detectors.
