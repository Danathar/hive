- The hive's own "🐝 Hive Advisory Report" and bot dependency dashboards (Renovate's "Dependency Dashboard", Dependabot's equivalent) no longer count as actionable issues. Both are standing meta issues — a report the hive files itself and machine-maintained control panels — so they inflated every repo's Actionable count permanently and were fed into agent kick prompts, where an agent "working" a Renovate dashboard can tick checkboxes that instruct Renovate to act. The contribute queue already denied both to human contributors by default; the agent path now applies the same judgment, structurally, at the same enumeration choice point as the hold/exempt checks. Real issues that merely mention dependencies stay actionable: the dashboard skip requires a known bot author AND a dashboard title.
