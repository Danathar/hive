- **`omnigent` contributor backend (T3 experimental).** Registered the Omnigent meta-harness CLI ([omnigent-ai/omnigent](https://github.com/omnigent-ai/omnigent), Apache-2.0) across `KNOWN_BACKENDS`, `CLIBackends`, local confinement matrix tests, and contributor preflights. Omnigent orchestrates Claude Code, Codex, Cursor, Pi, and custom agent harnesses; on the local CLI path it exposes no OS-level sandbox wired by Hive and requires explicit opt-in via `HIVE_OMNIGENT_DANGEROUSLY_RUN_UNCONFINED=1`. Omnigent's internal policy engine and sandboxing compose additively, while Hive's proxy remains strictly authoritative for all GitHub writes and push operations.
